markable

Plots written as HTML. A <data-plot> reads rows (from a <table>, a <datalist>, JSON, or a .data property) and works out the scales; layers inside it draw. Marks are copies of a <template> placed by CSS custom properties (--x, --y, --color, --size), and :attr="field" maps any field onto any element's attribute, 0 to 1. Each card runs the real source from ../src/.
